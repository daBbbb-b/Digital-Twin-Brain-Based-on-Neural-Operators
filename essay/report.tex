\begin{abstract}

本文探索利用神经算子构建数字大脑模型。我们基于结构连接（SC）和通过神经扰动推断得到的有效连接（EC）以及MNI 空间皮层表面拉普拉斯算子，利用神经动力学方程（ODE为E-I模型与PDE为神经波动模型）生成了仿真数据集。我们分别构建并训练了傅里叶神经算子（FNO）、DeepONet以及多层感知机（MLP）模型，模型训练目标为学习从fMRI BOLD数据到刺激的反演映射。

我们将训练好的模型（测试了用ODE数据集训练的FNO模型）迁移至真实fMRI数据应用中，尝试反演103个任务下的潜在刺激模式，并通过对比反演刺激图谱与经验功能激活图谱来评估模型性能。实验结果表明，当前模型反演的刺激分布与真实特定任务的fMRI BOLD数据之间相关性较低。我们最后从仿真数据覆盖度、信号预处理差异、模型训练目标、BOLD血氧动力学滞后性等角度尝试分析了差异原因，并提出了丰富仿真范式、优化数据处理流程等改进策略。
\end{abstract}

\section{背景}
\subsection{数字大脑模型简介}

“数字大脑”（Digital Twin Brain）通常指一个能够在计算机中\emph{近似复现}个体或群体大脑结构与功能的计算模型。它的核心目标不是简单地“画出大脑长什么样”，而是希望在给定结构连接（structural connectivity, SC）、有效/功能连接（effective/functional connectivity, EC/FC）以及外界刺激条件时，能够预测大脑活动如何进行变化，在实现这个之后就能够将模型用于多种途径，如大脑机制解释、疾病模拟与干预评估等。

从建模角度看，数字大脑往往需要同时处理多尺度信息：微观层面的神经元/局部回路，中观层面的脑区动力学，以及宏观层面的全脑网络耦合。传统路线包括基于神经质量模型（neural mass / neural field）或生物物理方程的全脑动力学仿真，以及以数据驱动为主的统计/深度学习预测模型。前者可解释性强但参数多、计算量大并且难以针对单一个体建模；后者预测能力强但往往依赖大量数据、泛化与物理一致性不足。因而，一个现实的挑战是：如何在\emph{可解释/可控}与\emph{可学习/可泛化}之间取得平衡，并让模型能更稳定地迁移到不同个体、不同扫描条件或不同任务状态。

\subsection{神经算子简介}

神经算子（Neural Operator）是一类用神经网络去学习“从函数到函数映射”的方法。与常见的神经网络学习有限维向量到向量的映射不同，神经算子更关注连续对象：例如从初始条件、边界条件等到 PDE 的映射。直观地说，神经算子想学到的是一个“算子”，学会后就可以对新的输入条件快速推断输出，而不需要每次都进行昂贵的重新适配与训练。

典型方法包括 Fourier Neural Operator（FNO）通过频域卷积在全局尺度上建模，适合表达具有较长输入的数据建模；DeepONet 通过分支网络与主干网络分别编码输入函数与查询位置，实现对算子的近似的实现。它们常被强调的一个特性是对分辨率/网格的相对“无关性”：在一定条件下，训练时与测试时的离散网格可以不同，从而更贴近“连续算子”的设定。这一点对于需要在不同空间采样或不同时间步长下工作的神经科学数据建模具有很大的价值。

\subsection{使用神经算子构建数字大脑模型的好处}

将数字大脑问题表述为算子学习问题，有助于把“从结构与状态到脑活动演化”的任务统一成一个可学习的映射框架。相比仅做短期时间序列预测的黑箱模型，神经算子更强调对函数映射的学习，这与脑仿真的目标更一致。具体而言，神经算子路线带来以下优势：

\begin{itemize}
    \item \textbf{更适合表达全局耦合与长程依赖：} 大脑是强网络耦合系统，跨脑区的相互影响往往具有非局部性。以 FNO 为代表的方法可在频域中高效建模全局交互，有利于捕捉长程的传播模式。
    \item \textbf{对分辨率变化更鲁棒：} 神经算子面向函数空间学习，在不同时间步长/空间采样下具备更好的迁移潜力，适合处理不同被试、不同预处理管线带来的采样差异。
\end{itemize}

基于以上动机和相关论文说明，我们尝试以神经算子为模型，在结构/连接信息与时空脑活动之间建立可泛化的映射，并与基础 MLP 等模型进行对比。

\section{神经算子}

我们尝试了神经算子（FNO 1D 和 DeepONet）和传统的 MLP 神经网络。整体目标是：学习一个从“输入状态/条件”到“输出时空活动/预测量”的映射，并在不同模型之间做对照，进行比较。

\subsection{FNO 1D 模型}
\textbf{核心思路：} 将一维序列（例如时间序列或沿一维网格采样的信号）视为“函数离散采样”，模型在频域对信号进行处理：先把输入提升到较高维的隐空间表示（一个简单的前向传播），再在频域保留有限个低频模态进行学习（先转换为频域，再人为设置取前几个模态作为处理对象），从而以较低计算成本捕捉长程依赖与全局结构，最后投影回输出维度得到预测序列。
\begin{figure}[h]
    \centering
    \includegraphics[width=0.8\textwidth]{images/FNO1D.png}
    \caption{FNO 1D 模型结构示意图（概念层级）}
    \label{fig:fno_1d_structure}
\end{figure}

\textbf{优势：} 大脑相关信号常同时包含局部波动与跨区互相影响。频域截断相当于对“主要形态/主导模式”建模，既提高稳定性，也减少对噪声高频的过拟合风险。

\textbf{适用场景与局限：}
\begin{itemize}
    \item 适合：需要建模长程依赖、全局传播模式、希望推断快且可扩展的序列/场预测任务。
    \item 局限：对非平稳的细粒度瞬时变化可能不如专门的局部时序模型敏感；频域截断强度需要通过验证集调参。
\end{itemize}

\subsection{DeepONet 模型}
\textbf{核心思路：} 将算子学习拆成两条路径：一条编码“输入函数”（例如在若干传感器位置/若干采样点处的取值或其特征表示），另一条编码“查询位置”（例如时间点或空间坐标）。两条表示在输出端进行融合，最终实现“给定输入函数，查询任意位置输出”的预测输出。
\begin{figure}[h]
    \centering
    \includegraphics[width=0.8\textwidth]{images/deeponet.png}
    \caption{DeepONet 模型结构示意图}
    \label{fig:deeponet_structure}
\end{figure}

\textbf{优势：} 这类结构符合“输入是函数、输出也是函数”的问题：模型不需要固定输出为整段序列，也可以在不同查询点上复用同一套输入函数表示，便于做插值/外推式的查询预测。

\textbf{适用场景与局限：}
\begin{itemize}
    \item 适合：输入可被少量采样点（传感器）概括、输出需要在不同坐标点查询的任务；需要灵活改变查询点集合的任务。
    \item 局限：输入采样点的选择会显著影响效果；若输入函数结构复杂而采样过少，容易信息不足。
\end{itemize}

\subsection{连接矩阵计算}
\subsubsection{结构连接矩阵}

结构连接（Structural Connectivity, SC）刻画了大脑各脑区之间通过白质纤维束连接的物理拓扑结构，是大尺度脑网络动力学模型的基础骨架。在本实验中，我们使用数据集提供的组平均白质结构连接矩阵。我们对原始 SC 矩阵进行了最大值归一化处理。

处理后的 SC 矩阵一方面用于生成基于 ODE 的仿真数据（定义耦合拓扑），另一方面作为“掩膜（Mask）”用于约束有效连接（EC）的稀疏性，即假设无解剖连接的区域间不存在直接的因果作用。

\subsubsection{有效连接矩阵}

有效连接（Effective Connectivity, EC）旨在刻画脑区之间\textbf{有方向性}、可解释为“因果影响”的相互作用强度。本文采用 Luo 等在 Nature Methods 提出的 NPI（Neural Perturbation Inference）框架：先训练一个能够复现统计连接结构的“代理大脑”（surrogate brain），再对该代理模型进行\textbf{虚拟扰动}以得到有向 EC 矩阵\cite{npi}。在推断 EC 前，我们先计算经验功能连接（Functional Connectivity, FC）用于训练监控与一致性验证。

\noindent\textbf{(1) 经验功能连接矩阵（FC）计算：}
对每个被试的每个 run，我们首先将体素级 fMRI 信号映射到 ROI 级时间序列：使用 BNA 246 分区图谱对齐到 fMRI 标准空间（MNI152NLin2009cAsym），并对每个 ROI 内体素时间序列取均值，得到
\[
\mathbf{X}\in\mathbb{R}^{T\times N},\quad N=246,
\]
其中 $T$ 为时间点数，$N$ 为脑区数。经验 FC 采用 Pearson 相关系数计算：
\[
FC_{ij}=\frac{\mathrm{cov}(x_i,x_j)}{\sigma_{x_i}\sigma_{x_j}},
\]
其中 $x_i,x_j$ 分别表示第 $i/j$ 个脑区的 ROI 时间序列。由此得到对称矩阵 $FC\in\mathbb{R}^{N\times N}$，对角线为 1，反映脑区间的统计相关性结构。

\noindent\textbf{(2) 代理大脑训练（NPI 的 surrogate brain）：}
NPI 的核心是训练一个可递归生成序列的预测模型，使其产生的模拟信号在统计意义上复现经验 FC\cite{npi}。本文采用多层感知机（MLP）作为代理模型，使用多步到一步的输入输出形式：
\[
\hat{\mathbf{x}}_{t+1}=f_{\theta}\!\left(\mathbf{x}_{t},\mathbf{x}_{t-1},\mathbf{x}_{t-2}\right),
\]
即输入为连续 3 个时间点（steps=3）的脑区状态，输出为下一时间点的脑区状态。训练目标为最小化单步预测均方误差（MSE）：
\[
\mathcal{L}(\theta)=\left\| f_{\theta}(\mathbf{x}_{t},\mathbf{x}_{t-1},\mathbf{x}_{t-2})-\mathbf{x}_{t+1}\right\|_2^2 .
\]
训练完成后，将模型输出递归反馈作为下一步输入，可生成较长的模拟时间序列，并计算其 $FC_{\text{sim}}$ 与经验 $FC_{\text{emp}}$ 的相关性作为一致性检查指标（论文中以较高相关作为“代理大脑”有效性的判据\cite{npi}）。

\noindent\textbf{(3) 虚拟扰动与 EC 推断：}
在代理模型上对每个脑区施加脉冲扰动以估计其对其他脑区的有向影响\cite{npi}。对第 $i$ 个脑区，在时刻 $t$ 的输入 $\mathbf{x}_t$ 上加入扰动：
\[
\mathbf{x}_t'=\mathbf{x}_t+\Delta_i \mathbf{e}_i,
\]
其中 $\mathbf{e}_i$ 为第 $i$ 维为 1 的单位向量，扰动强度 $\Delta_i$ 取该脑区时间序列标准差的一半（兼顾扰动可检测性与模型稳定性）。分别计算基线预测与扰动预测：
\[
\hat{\mathbf{x}}^{\text{base}}_{t+1}=f_{\theta}(\mathbf{x}_{t},\mathbf{x}_{t-1},\mathbf{x}_{t-2}),\quad
\hat{\mathbf{x}}^{\text{pert}}_{t+1}=f_{\theta}(\mathbf{x}'_{t},\mathbf{x}_{t-1},\mathbf{x}_{t-2}),
\]
并取差值响应
\[
\Delta\mathbf{x}_{t+1}^{(i)}=\hat{\mathbf{x}}^{\text{pert}}_{t+1}-\hat{\mathbf{x}}^{\text{base}}_{t+1}.
\]
对所有时间点的响应进行平均（或稳健统计聚合），即可得到第 $i$ 个脑区对所有目标脑区的平均影响强度，从而构造有向矩阵
\[
EC_{ij}=\mathbb{E}_t\left[\Delta x^{(i)}_{t+1,j}\right],\quad EC\in\mathbb{R}^{N\times N},
\]
其中 $EC_{ij}$ 表示“脑区 $i$ 影响脑区 $j$”的方向性作用，正/负号可对应兴奋/抑制效应（在代理动力学的意义下）。

\noindent\textbf{(4) 结构连接约束（SC mask）：}
为保证 EC 的解剖合理性，我们使用二值结构连接矩阵 $SC\in\{0,1\}^{N\times N}$ 作为掩膜，将无结构连边处的 EC 置零：
\[
EC \leftarrow EC\odot SC,
\]
其中 $\odot$ 表示逐元素乘法。最终得到满足结构约束的有向 EC 矩阵用于后续分析。

\subsubsection{皮层表面拉普拉斯算子}
为了在皮层表面模拟 PDE 形式的神经动力学，我们在离散三角网格上构建拉普拉斯算子，步骤如下：

\noindent\textbf{(1) 拓扑提取：} 利用 \texttt{nibabel} 读取 MNI 空间皮层表面文件（.gii），获取网格顶点集合 $\mathcal{V}$ 与三角形面集合 $\mathcal{F}$。

\noindent\textbf{(2) 算子构建：} 基于网格连接关系构建稀疏邻接矩阵 $\mathbf{A}$（若顶点相邻则 $A_{ij}=1$）与度矩阵 $\mathbf{D}$（$D_{ii} = \sum_{j} A_{ij}$），进而得到组合图拉普拉斯算子：
\(
\mathbf{L} = \mathbf{D} - \mathbf{A}
\)
在 PDE 仿真中，该算子 $\mathbf{L}$ 近似表示流形上的 Laplace-Beltrami 算子，用于计算神经活动在皮层表面的空间扩散项 $-k \mathbf{L} \mathbf{x}$。

\subsection{仿真数据生成}
为了构建具有明确基准真值的数据集以训练神经算子，我们利用神经动力学方程生成了包含结构/有效连接约束的大规模仿真数据。仿真涵盖了基于 ODE 的宏观网络模型和基于 PDE 的皮层连续场模型。

最终生成数据集包含1000个基于EC的ODE仿真样本，1000个基于SC的ODE仿真样本，以及500个基于拉普拉斯算子的PDE仿真样本。每个样本均包含输入刺激信号与对应的BOLD响应时间序列，供神经算子模型训练使用。

\subsubsection{多样化刺激生成与 BOLD 信号转换}
为了训练神经算子学习从神经活动到输入刺激的反演映射，我们构建了一个能够生成复杂时空模式的刺激生成器。
\begin{itemize}
    \item \textbf{刺激模式：} 包含三种波形：(1) \textbf{Boxcar}：模拟持续性任务激活；(2) \textbf{Impulse}：模拟稀疏事件相关刺激；(3) \textbf{Continuous}：混合正弦波模拟自然持续信号。
    \item \textbf{观测模型：} 仿真得到的神经活动通过 Balloon-Windkessel 血氧动力学模型转换为 BOLD 信号，该模型包含非线性微分方程组，描述了血流、血容积及脱氧血红蛋白含量的动态变化\cite{dcm}。
\end{itemize}
\subsubsection{基于 ODE 的网络动力学仿真}
对于基于脑区划分（ROI）的微观/宏观动力学，我们采用经典的 Reduced Wong-Wang (EI) 模型\cite{deco2014}。该模型通过平均场近似描述了每个脑区内兴奋性（E）和抑制性（I）神经元群体的突触门控变量动态。

\textbf{动力学方程：} 对于第 $i$ 个脑区，其状态演化遵循：
\begin{align}
    \frac{dS_E^{(i)}}{dt} &= -\frac{S_E^{(i)}}{\tau_E} + (1-S_E^{(i)})\gamma H_E(I_E^{(i)}) \\
    \frac{dS_I^{(i)}}{dt} &= -\frac{S_I^{(i)}}{\tau_I} + H_I(I_I^{(i)})
\end{align}
其中 $S_E, S_I$ 分别为兴奋与抑制突触门控变量。输入电流 $I_E^{(i)}, I_I^{(i)}$ 包含局部耦合、全脑网络耦合及外部刺激：
\begin{align}
    I_E^{(i)} &= W_E I_0 + w_{EE} S_E^{(i)} + G J_{NMDA} \sum_{j} C_{ij} S_j^{(i)} - w_{EI} S_I^{(i)} + u^{(i)}(t) + \eta_E(t) \\
    I_I^{(i)} &= W_I I_0 + w_{IE} S_E^{(i)} - S_I^{(i)} + \eta_I(t)
\end{align}
其中 $C_{ij}$ 为连接矩阵，$G$ 为全局耦合强度。外部刺激 $u^{(i)}(t)$ 设计为空间稀疏输入，每次任务事件随机激活 $1 \sim 5$ 个脑区，模拟特定功能的局部激活；噪声项 $\eta(t)$ 为服从 $N(0, 0.02)$ 分布的高斯白噪声，用于模拟神经元群体的背景随机涨落。

\textbf{参数设置：} 时间常数 $\tau_E=100$ ms, $\tau_I=10$ ms；全局耦合强度 $G=0.5$；数值积分步长 $dt=0.5$ ms。我们在两种连接矩阵上生成数据：(1) \textbf{ODE-SC}：使用组平均白质结构连接矩阵；(2) \textbf{ODE-EC}：使用 NPI 推断得到的有效连接矩阵。

\subsubsection{基于 PDE 的皮层波动力学仿真}
为了模拟皮层表面的连续时空神经活动，我们采用定义在流形上的阻尼波动方程，该方程能够生成具有有限传播速度的行波模式，符合皮层神经场理论。

\textbf{动力学方程：} 定义皮层神经场活动 $u(\mathbf{x}, t)$\cite{g}，其演化方程为：
\[
\frac{\partial^2 u}{\partial t^2} + \gamma \frac{\partial u}{\partial t} + c^2 \Delta_{\mathcal{M}} u = \alpha \sigma(u) + I_{stim}(\mathbf{x}, t) + \xi(\mathbf{x}, t)
\]
离散化形式基于图拉普拉斯算子 $\mathbf{L}$：
\[
\frac{d\mathbf{v}}{dt} = -\gamma \mathbf{v} - c^2 \mathbf{L}\mathbf{u} + \alpha \sigma(\mathbf{u}) + \mathbf{u}_{ext}(t)
\]
其中 $v = \dot{u}$，$\gamma$ 为阻尼系数，$c$ 为波速，$\sigma(\cdot)$ 为 Sigmoid 非线性激活函数。外部输入 $\mathbf{u}_{ext}(t)$ 包含两部分：(1) 任务刺激 $I_{stim}$，其空间分布由 $1 \sim 5$ 个随机顶点为中心的高斯核定义，模拟皮层上的局部兴奋源；(2) 时空噪声场 $\xi$，在每个网格点独立采样自 $N(0, 0.01)$，为系统引入持续的随机扰动。

\textbf{参数设置：} 阻尼系数 $\gamma = 0.23 \, \text{ms}^{-1}$，波速 $c = 2.0 \, \text{mm/ms}$，非线性增益 $\alpha = 100.0$。仿真在包含约 3万顶点的左半球皮层网格上进行。

\subsubsection{数据加载}

训练数据为 \texttt{.pkl} 文件。每个样本包含一段多通道时间fMRI BOLD序列信号，以及与之对齐的刺激/输入序列。

\textbf{张量形状：} 将一段序列表示为 $(\text{Time},\ \text{Channels})$ 的矩阵；训练时整理为批量张量 $(N,\ T,\ C)$，其中 $N$ 为样本数，$T$ 为序列长度（或切片长度），$C$ 为通道数。

\textbf{预处理与切分：}
\begin{itemize}
    \item 数值清洗：对异常值（如 NaN）进行处理，避免训练过程出现不稳定或报错。
    \item 可选归一化：对每个通道进行 Z-score 标准化，使数据分布更加平稳。
    \item 序列切分：长序列可按固定长度 $T$ 切分为多个样本；若选择不切分，则直接使用整段序列。本文默认设置为：ODE 数据使用 $T=1024$ 的切片；PDE 数据使用整段序列（不切分）。
\end{itemize}

\subsubsection{FNO 模型训练}

FNO（1D）将时间序列视为一维网格上的多通道函数，学习从信号序列到刺激/输入序列的映射：
\[

\subsection{反演任务：由fMRI数据输入预测刺激}
反演任务中，我们仅测试了基于EC的ODE仿真数据训练的 FNO 模型、基于SC的ODE仿真数据训练的 FNO 模型，以及使用PDE仿真数据集训练的 FNO 模型。

为了验证神经算子模型在真实生物数据上的反演能力，我们将训练好的 FNO 模型迁移至真实 fMRI 数据应用中。由于真实数据的采集参数与仿真环境存在差异，我们设计了一套完整的预处理与推理适配流程。

\subsubsection{数据预处理}

原始 fMRI 数据为 4D NIfTI 格式（$x, y, z, t$），体素数量巨大且包含大量背景噪声。为了与网络动力学模型（ODE-SC/EC）的节点定义保持一致，我们首先将体素级信号映射至 ROI 级时间序列。

使用 \texttt{nilearn} 库的 \texttt{NiftiLabelsMasker} 工具，配合 Brainnetome Atlas 246 (BNA) 图谱（\texttt{BN\_Atlas\_246\_1mm.nii.gz}）对原始 fMRI 影像进行掩膜处理。对于图谱定义的 246 个脑区，计算区域内所有体素的平均强度作为该节点的 BOLD 信号。

\subsubsection{训练数据修正与模型调优}
在初步实验中，我们直接使用 FNO 模型对真实数据进行反演，发现输出的潜在刺激 $u(t)$ 呈现为无波动的“死线”。经排查，原仿真训练集中的 BOLD 信号缺乏足够的动态变化范围，导致模型收敛于平均值映射。

为此，我们优化了模型的仿真参数，重新生成了覆盖更广动态范围的高质量 BOLD-Stimulus 数据对，并重新训练了 FNO 模型。此外，为了保持真实信号的物理幅值特性，我们在推理阶段\textbf{未对输入数据进行 Z-score 归一化}，而是直接使用原始 BOLD 幅值，使其与仿真数据的分布特性保持一致。这一调整显著改善了反演结果，使模型能够输出具备生理合理性的波动信号。

\subsubsection{推理策略与时空适配}
\paragraph{\textbf{时序重采样}}
真实 fMRI 数据的重复时间（TR）通常为 2.0s，而神经算子模型是在 $dt=0.05s$ 的高频仿真数据上训练的。为解决时间分辨率的不匹配，我们采用线性插值将真实 BOLD 信号升采样至 0.05s 间隔。虽然这在一定程度上引入了平滑误差，但保证了输入数据在时域尺度上适配神经算子对高频动力学的捕捉需求。

\paragraph{\textbf{Look-back 拼接策略}}
由于 FNO 模型的输入窗口长度固定为 $T=1024$（ 51.2s），而真实 fMRI 扫描的时长通常远大于此（560s），我们需要将长序列切分为多个窗口进行推理。
常规的“补零填充（Zero-padding）”策略在处理序列尾部不足一个窗口的数据时，会导致 FNO 模型（基于频域全局特性）在边缘处产生剧烈的吉布斯震荡和伪影，严重影响反演质量。

为此，我们实施了\textbf{“回退截取”策略}。具体逻辑为：
\begin{enumerate}
    \item 对于序列的前半部分，按步长 $T$ 正常切分窗口进行推理；
    \item 当处理最后一段长度不足 $T$ 的数据时，\textbf{不进行补零}，而是从序列末尾向前回溯，截取一个完整的 $T=1024$ 长度的窗口输入模型；
    \item 在获取该窗口的输出后，仅截取对应尾部的新增时间步拼接到总结果中。
\end{enumerate}

如图所示，该策略成功消除了拼接处的数据突变与边缘震荡，保证了全时段反演信号的平滑性和连续性，有效解决了长程 fMRI 信号的推理难题。

\subsection{可视化与一致性分析}
可视化部分我们对基于EC的ODE仿真数据训练的 FNO 模型反演结果和基于SC的ODE仿真数据训练的 FNO 模型反演结果进行可视化分析。

为验证模型输出与真实脑活动的匹配程度，我们从时间维度和空间维度开展可视化分析，并通过相关性量化一致性水平。

\subsubsection{可视化方法}
\paragraph{1. 时间维度}
以 \textit{trial type} 作为区分锚点，将每个脑区的刺激强度在时间上与 \textit{task} 对应，绘制出各个脑区刺激强度在每种 \textit{trial} 中随时间的变化曲线，重点分析单个脑区在不同任务范式下的时序响应特征，捕捉刺激信号的动态变化规律。

\paragraph{2. 空间维度}
基于 \textit{brainspace} 库实现全脑尺度的空间可视化：对每种 \textit{task} 中全脑区的平均信号强度进行建模，将数值映射为玻璃脑的颜色梯度，直观呈现不同任务下全脑激活的空间分布模式，对比真实功能图谱与模型预测图谱的空间一致性。

\subsubsection{功能图谱计算}
\paragraph{1. 真实功能图谱（Functional Activation Map）}
来源为真实 BOLD 数据，计算方式为对任务时间窗内的 BOLD 信号取均值，并减去非任务时间窗的均值：
\[
\text{FuncMap}(k) = \mathbb{E}\left[x(t) \mid \text{task on}\right] - \mathbb{E}\left[x(t) \mid \text{task off}\right]
\]
其中 $k$ 代表脑区编号，$x(t)$ 为脑区 $k$ 在时刻 $t$ 的 BOLD 信号值，该图谱反映脑区在任务态下的真实激活强度。

\paragraph{2. 刺激图谱（Stimulus Map）}
来源为模型反演的刺激数据，计算方法与功能图谱一致：对任务时间窗内的反演刺激信号取均值，并减去非任务时间窗的均值：
\[
\text{StimMap}(k) = \mathbb{E}\left[\hat{u}(t) \mid \text{task on}\right] - \mathbb{E}\left[\hat{u}(t) \mid \text{task off}\right]
\]
其中 $\hat{u}(t)$ 为模型预测的脑区 $k$ 在时刻 $t$ 的刺激信号值，用于与真实功能图谱做空间和数值对比。

\section{讨论}
从一致性分析结果可知，模型预测的刺激图谱和预测图谱之间几乎不存在线性相关性，我们尝试从实验流程各个阶段考虑原因：
\begin{itemize}
    \item \textbf{连接矩阵}：EC矩阵和SC矩阵均使用相同的E-I方程进行仿真，但两种矩阵的数值差异可能造成一定影响，导致基于EC和SC训练的神经算子反演结果相似度较低。
    \item \textbf{仿真数据}：模拟刺激种类有限，当前只考虑了三种刺激，仅使用了简单的白噪声；刺激作用的脑区为随机选择的1-5个脑区，本实验希望通过增加仿真数据量实现全脑区和不同组合脑区的覆盖，但仅1000组仿真数据无法实现不同组合脑区组合的全覆盖；仿真数据的动力学方程参数设置可能与真实大脑动力学差异较大，导致生成的BOLD信号与真实信号在统计特性上存在偏差，并且随着时间累计差异进一步增大。
    \item \textbf{模型训练}：模型直接进行反演任务可能是一个病态任务，反演本身已经颠倒了因果（正确应该为刺激为因，神经信号为果），反演任务的正确性有待进一步验证；神经算子模型的超参数设置（如隐空间宽度、频域模态数等）可能未能充分挖掘数据中的潜在模式，导致模型表达能力不足；训练轮数较少可能未能使模型充分收敛，影响预测性能。
    \item \textbf{fMRi数据反演}：真实fMRI数据为低频(2s)采样信号,当前通过简单线性插值恢复到高频(0.5ms)信号，插值方法可能未能有效捕捉真实信号的动态特性，影响模型输入的质量；fMRI BOLD 信号天然包含生理噪声与扫描设备噪声，模型在反演是没有对这类非任务相关噪声进行处理。
    \item \textbf{一致性分析}：刺激图谱使用刺激信号，真实图谱使用BOLD信号，BOLD信号一般存在滞后效应，二者在时间上存在偏移，直接计算空间相关性可能低估了真实一致性水平；当前的刺激图谱和真实功能图谱均采用简单的均值差分计算，可能未能充分捕捉复杂的任务相关激活模式，影响一致性评估的准确性。
\end{itemize}

本次实验虽然未能实现预期的一致性，但分析整个实验流程的问题后，我们认为可以从以下几个方面进行改进：
\begin{itemize}
    \item \textbf{丰富仿真数据}：增加仿真数据量，覆盖更多脑区组合和刺激模式；利用脑区先验，如预先计算各任务的活跃脑区，在仿真数据中针对性施加刺激，根据任务需求设计刺激方案；引入更复杂的噪声模型，模拟更接近真实大脑环境的背景活动；调整动力学方程参数，使生成的BOLD信号在统计特性上更接近真实信号。
    \item \textbf{优化模型训练}：调整神经算子模型的超参数，如增加隐空间宽度和频域模态数，以提升模型的表达能力；增加训练轮数，确保模型充分收敛；尝试不同的优化器和学习率调度策略，以改善训练过程。
    \item \textbf{改进fMRI数据处理}：采用更先进的插值方法，如基于小波变换或深度学习的方法，以更准确地恢复高频信号特性；在反演前对fMRI数据进行更细致的预处理，减弱生理噪声和扫描设备噪声，提高输入数据质量。
    \item \textbf{完善一致性分析}：考虑BOLD信号的滞后效应，在计算空间相关性时引入时间偏移校正；采用更复杂的功能图谱计算方法，如GLM分析等，以更准确地捕捉任务相关激活模式，提高一致性评估的准确性。    
    \item \textbf{完善模型探索}：本次任务由于时间有限的原因，我们虽然在不同数据集上训练好的FNO、DeepONet和MLP模型，但只使用了FNO模型进行反演任务。后续可以尝试使用DeepONet和MLP模型进行反演任务，并对比不同模型的反演效果，从而选择最优的神经算子架构。
\end{itemize}

\section{总结}

\indent 本文初步探索了将神经算子技术应用于数字大脑建模及大脑状态反演的可行性,测试了神经算子的分辨率无关、泛化能力强的特性。通过构建包含微观网络动力学与宏观皮层波动的多尺度仿真数据集，我们训练了 FNO 等算子模型，并建立了一套从神经动力学仿真到真实 fMRI 数据反演的完整实验流水线。尽管目前的实验结果显示，基于简化仿真数据训练的模型在迁移至真实大脑环境时，其反演的潜在刺激分布与经验功能激活图谱远未达到理想的统计一致性，但我们尝试从多个角度分析了可能的影响因素，并提出了一些后续可能的改进方式。

\section{附录：代码文件说明}

存放于code/文件夹，主要文件目录结构及其功能说明如下：

\subsection*{1. 模型定义模块 (models/)}
该文件夹包含本报告中对比实验所涉及的三种神经网络架构的底层实现：
\begin{itemize}
    \item \texttt{fno.py}：傅里叶神经算子（FNO 1D）模型实现。代码定义了基于快速傅里叶变换（FFT）的谱卷积层，用于提取神经信号的频域特征。
    \item \texttt{deeponet.py}：DeepONet 模型实现。包含用于编码输入函数的分支网络（Branch Net）和编码查询坐标的主干网络（Trunk Net）。
    \item \texttt{mlp.py}：多层感知机（MLP）基线模型实现。
\end{itemize}

\subsection*{2. 动力学仿真模块 (simulation/ \& dynamics/)}
用于基于生物物理方程生成包含基准真值（Ground Truth）的仿真数据集：
\begin{itemize}
    \item \texttt{simulation/ode\_simulator.py}：基于 SC/EC 连接矩阵的宏观网络动力学仿真器，集成了 Reduced Wong-Wang 模型的数值积分过程。
    \item \texttt{simulation/pde\_simulator.py}：基于皮层表面流形的 PDE 神经场仿真器，实现了利用拉普拉斯算子计算空间扩散的过程。
    \item \texttt{simulation/stimulation\_generator.py}：刺激生成器，支持生成 Boxcar（持续）、Impulse（脉冲）及 Continuous（连续）等多种模式的外部输入信号。
    \item \texttt{dynamics/}：核心动力学方程库。包含神经元群体的突触门控方程以及将神经活动转换为 BOLD 信号的 Balloon-Windkessel 血氧模型实现。
\end{itemize}

\subsection*{3. 模型训练模块 (training/)}
\begin{itemize}
    \item \texttt{train\_fno1d.py}：FNO 模型的训练主程序，包含数据集划分、MSE 损失计算及验证集模型优选逻辑。
    \item \texttt{train\_deeponet.py} / \texttt{train\_mlp.py}：DeepONet 与 MLP 模型的对应训练脚本。
    \item \texttt{train\_mlp.py}：MLP 模型的训练主程序。
    \item \texttt{data\_loader.py}：数据加载工具，负责处理 .pkl 格式的仿真数据，实现时间序列切分与归一化。
\end{itemize}

\subsection*{4. 评估与反演模块 (evaluation/)}
\begin{itemize}
    \item \texttt{run\_inference.py}：推理主脚本。实现了加载预训练模型对真实 fMRI 数据进行反演的核心逻辑，包括报告中提到的“Look-back 回退拼接策略”以处理长序列。
    \item \texttt{preprocess\_bold.py}：真实数据的预处理脚本，包含 ROI 信号提取及时间序列的线性插值（Upsampling）操作。
\end{itemize}
