\section{背景}
\subsection{数字大脑模型简介}
“数字大脑”（Digital Twin Brain）通常指一个能够在计算机中\emph{近似复现}个体或群体大脑结构与功能的计算模型。它的核心目标不是简单地“画出大脑长什么样”，而是希望在给定结构连接（structural connectivity, SC）、有效/功能连接（effective/functional connectivity, EC/FC）以及外界刺激条件时，能够预测大脑活动如何进行变化，在实现这个之后就能够将模型用于多种途径，如大脑机制解释、疾病模拟与干预评估等。

从建模角度看，数字大脑往往需要同时处理多尺度信息：微观层面的神经元/局部回路，中观层面的脑区动力学，以及宏观层面的全脑网络耦合。传统路线包括基于神经质量模型（neural mass / neural field）或生物物理方程的全脑动力学仿真，以及以数据驱动为主的统计/深度学习预测模型。前者可解释性强但参数多、计算量大并且难以针对单一个体建模；后者预测能力强但往往依赖大量数据、泛化与物理一致性不足。因而，一个现实的挑战是：如何在\emph{可解释/可控}与\emph{可学习/可泛化}之间取得平衡，并让模型能更稳定地迁移到不同个体、不同扫描条件或不同任务状态。

\subsection{神经算子简介}
神经算子（Neural Operator）是一类用神经网络去学习“从函数到函数映射”的方法。与常见的神经网络学习有限维向量到向量的映射不同，神经算子更关注连续对象：例如从初始条件、边界条件等到 PDE 的映射。直观地说，神经算子想学到的是一个“算子”，学会后就可以对新的输入条件快速推断输出，而不需要每次都进行昂贵的重新适配与训练。

典型方法包括 Fourier Neural Operator（FNO）通过频域卷积在全局尺度上建模，适合表达具有较长输入的数据建模；DeepONet 通过分支网络与主干网络分别编码输入函数与查询位置，实现对算子的近似的实现。它们常被强调的一个特性是对分辨率/网格的相对“无关性”：在一定条件下，训练时与测试时的离散网格可以不同，从而更贴近“连续算子”的设定。这一点对于需要在不同空间采样或不同时间步长下工作的神经科学数据建模具有很大的价值。

\subsection{使用神经算子构建数字大脑模型的好处}
将数字大脑问题表述为算子学习问题，有助于把“从结构与状态到脑活动演化”的任务统一成一个可学习的映射框架。相比仅做短期时间序列预测的黑箱模型，神经算子更强调对函数映射的学习，这与脑仿真的目标更一致。具体而言，神经算子路线带来以下优势：

\begin{itemize}
    \item \textbf{更适合表达全局耦合与长程依赖：} 大脑是强网络耦合系统，跨脑区的相互影响往往具有非局部性。以 FNO 为代表的方法可在频域中高效建模全局交互，有利于捕捉长程的传播模式。
    \item \textbf{对分辨率变化更鲁棒：} 神经算子面向函数空间学习，在不同时间步长/空间采样下具备更好的迁移潜力，适合处理不同被试、不同预处理管线带来的采样差异。
\end{itemize}

基于以上动机和相关论文说明，我们尝试以神经算子为模型，在结构/连接信息与时空脑活动之间建立可泛化的映射，并与基础 MLP 等模型进行对比。

\section{神经算子}
我们尝试了神经算子（FNO 1D 和 DeepONet）和传统的 MLP 神经网络。整体目标是：学习一个从“输入状态/条件”到“输出时空活动/预测量”的映射，并在不同模型之间做对照，进行比较。

\subsection{FNO 1D 模型}
\textbf{核心思路：} 将一维序列（例如时间序列或沿一维网格采样的信号）视为“函数离散采样”，模型在频域对信号进行处理：先把输入提升到较高维的隐空间表示（一个简单的前向传播），再在频域保留有限个低频模态进行学习（先转换为频域，再人为设置取前几个模态作为处理对象），从而以较低计算成本捕捉长程依赖与全局结构，最后投影回输出维度得到预测序列。
\begin{figure}[h]
    \centering
    \includegraphics[width=0.8\textwidth]{images/FNO1D.png}
    \caption{FNO 1D 模型结构示意图（概念层级）}
    \label{fig:fno_1d_structure}
\end{figure}

\textbf{优势：} 大脑相关信号常同时包含局部波动与跨区互相影响。频域截断相当于对“主要形态/主导模式”建模，既提高稳定性，也减少对噪声高频的过拟合风险。

\textbf{适用场景与局限：}
\begin{itemize}
    \item 适合：需要建模长程依赖、全局传播模式、希望推断快且可扩展的序列/场预测任务。
    \item 局限：对非平稳的细粒度瞬时变化可能不如专门的局部时序模型敏感；频域截断强度需要通过验证集调参。
\end{itemize}

\subsection{DeepONet 模型}
\textbf{核心思路：} 将算子学习拆成两条路径：一条编码“输入函数”（例如在若干传感器位置/若干采样点处的取值或其特征表示），另一条编码“查询位置”（例如时间点或空间坐标）。两条表示在输出端进行融合，最终实现“给定输入函数，查询任意位置输出”的预测输出。
\begin{figure}[h]
    \centering
    \includegraphics[width=0.8\textwidth]{images/deeponet.png}
    \caption{DeepONet 模型结构示意图（概念层级）}
    \label{fig:deeponet_structure}
\end{figure}

\textbf{优势：} 这类结构符合“输入是函数、输出也是函数”的问题：模型不需要固定输出为整段序列，也可以在不同查询点上复用同一套输入函数表示，便于做插值/外推式的查询预测。

\textbf{适用场景与局限：}
\begin{itemize}
    \item 适合：输入可被少量采样点（传感器）概括、输出需要在不同坐标点查询的任务；需要灵活改变查询点集合的任务。
    \item 局限：输入采样点的选择会显著影响效果；若输入函数结构复杂而采样过少，容易信息不足。
\end{itemize}

\subsection{模型训练}
\subsubsection{数据加载}

训练数据为 \texttt{.pkl} 文件。每个样本包含一段多通道时间序列信号，以及与之对齐的刺激/输入序列（没有直接给出，需要由刺激描述重建得到）。

\textbf{张量形状：} 将一段序列表示为 $(\text{Time},\ \text{Channels})$ 的矩阵；训练时整理为批量张量 $(N,\ T,\ C)$，其中 $N$ 为样本数，$T$ 为序列长度（或切片长度），$C$ 为通道数。

\textbf{预处理与切分：}
\begin{itemize}
    \item 数值清洗：对异常值（如 NaN）进行处理，避免训练过程出现不稳定或报错。
    \item 可选归一化：对每个通道进行 Z-score 标准化，使数据分布更加平稳。
    \item 序列切分：长序列可按固定长度 $T$ 切分为多个样本；若选择不切分，则直接使用整段序列。本文默认设置为：ODE 数据使用 $T=1024$ 的切片；PDE 数据使用整段序列（不切分）。
\end{itemize}

\subsubsection{FNO 模型训练}

FNO（1D）将时间序列视为一维网格上的多通道函数，学习从信号序列到刺激/输入序列的映射：
\[
\mathcal{G}_{\theta}:\ \mathbf{x}(\cdot) \mapsto \mathbf{u}(\cdot).
\]
训练流程为：将数据整理为 $(N,\ T,\ C)$ 的批量张量，按 8:2 划分训练集与验证集；采用均方误差（MSE）作为回归损失，使用 Adam 优化；每个 epoch 在验证集上评估并保留验证误差最小的模型权重。

\subsubsection{DeepONet 模型训练}

DeepONet 将“输入函数”和“查询坐标”分开编码：分支网络编码输入序列（多通道信号的取值），主干网络编码查询坐标（本文使用归一化时间坐标）；两者融合后输出该坐标处的刺激/输入预测值。其目标可写为
\[
\hat{\mathbf{u}}(t)=\mathcal{G}_{\theta}(\mathbf{x},\ \mathbf{y}(t)).
\]
训练时对时间轴上的各个查询点进行监督，使用 MSE 损失与 Adam 优化，并以验证集误差最小的模型作为最终结果。
